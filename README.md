 
# 🎙️ AI-Powered Voice Chatbot Application

**An Intelligent, Locally Running AI Conversational Assistant**

## 1. Project Overview

The AI-Powered Voice Chatbot application is a Python-based conversational application that enables users to interact with Artificial Intelligence through natural spoken conversations rather than typing.

The application listens to user queries, converts speech into text, processes the input using a Large Language Model (LLM), and generates intelligent responses in natural speech.

The primary objective is to develop an intelligent, responsive and privacy-conscious Voice Chatbot using free and open-source AI technologies, running entirely on local infrastructure without depending on paid AI APIs.

**Project Category:** Artificial Intelligence | Machine Learning | NLP | Generative AI

**Challenge:** Decoding Data Science – Building Agentic AI Applications

## 2. Project Goals and Objectives

- Develop a voice-enabled conversational AI application.
- Implement Speech-to-Text (STT) for recognizing spoken user queries.
- Integrate an LLM for contextual understanding and intelligent response generation.
- Implement Text-to-Speech (TTS) to generate spoken responses.
- Enable multi-turn conversations and conversational context.
- Minimize operational costs by leveraging open-source technologies and locally deployed models.
- Establish a foundation for future RAG and Agentic AI capabilities.

## 3. Key Features

1. **Voice-Based Interaction:** Capture user speech and convert it into text using automatic speech recognition.
2. **Intelligent Conversational AI:** Understand questions, maintain conversation context and generate relevant responses using an LLM.
3. **Natural Voice Responses:** Convert AI-generated text into spoken responses using a local Text-to-Speech engine.

## 4. Technology Stack

| Component | Technology |
|---|---|
| Programming Language | Python 3.15 |
| Speech Recognition | Faster-Whisper |
| LLM Runtime | Ollama |
| Language Model | Llama 3.2 3B |
| NLP | Hugging Face Transformers |
| Text-to-Speech | Piper |
| Audio Processing | SoundDevice, SoundFile |
| Application Interface | Streamlit |
| Development Environment | Visual Studio Code |
| Operating System | Windows 11 |

All core components are intended to run locally using free or open-source software and appropriately licensed models.


## 5. Project Prerequisites

The initial development environment:

- Operating System: Windows 11
- RAM: 16 GB
- GPU: No dedicated GPU (CPU-based execution)
- Python: Version 3.15
- Internet: Required initially for downloading software and models; not required for normal local inference after setup.

## 7. Data Sources and Evaluation

The project will leverage publicly available speech datasets and custom evaluation data.

| Dataset / Resource | Purpose |
|---|---|
| LibriSpeech | Speech recognition benchmarking |
| Custom Voice Dataset | Real-world voice input testing |

Evaluation metrics will include:

- Word Error Rate (WER)
- Character Error Rate (CER)
- Response Relevance
- Context Retention
- End-to-End Response Latency
- Speech Intelligibility

The expected outcome is a fully functional, locally deployed AI Voice Chatbot that can listen, understand and respond naturally through voice conversations.
